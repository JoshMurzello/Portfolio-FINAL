Self Balancing Robot

A control-system prototype focused on keeping an unstable two-wheel platform upright using sensor feedback, motor response, and fast iteration.

Core Loop

Sense, estimate, correct

The project centers on reading tilt state, estimating the robot's orientation, and converting error into motor correction.

Learning Goal

Controls under real friction

The interesting work is tuning behavior around battery sag, drivetrain backlash, floor variation, and sensor noise.

Next Pass

Document the tuning

The next page upgrade should show the control diagram, PID changes, failure modes, and short balancing clips.

What this project proves

Self-balancing robots are useful because they expose the full stack of a controls problem quickly. A small mechanical change can force a software retune, and a software assumption shows up immediately as oscillation, drift, or a fall.

  • Mechanical layout affects controller stability just as much as the code.
  • Fast loop timing matters more than a visually polished enclosure in early testing.
  • Good demos need the failed tuning runs too, because that is where the engineering judgment is visible.
