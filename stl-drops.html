FAQ

Release policies for the framework

Will every STL require an email unlock?

The framework assumes yes for free drops, with immediate on-page unlock and a transparent note that signup also covers occasional future release emails.

What printers and settings will be supported?

Each release should include printer fit guidance, estimated print time, recommended material, layer height, and any support or orientation notes.

Can people use the files commercially?

The current direction is personal-use distribution first, with commercial licensing handled separately for anyone who wants to sell prints.

Will the STL be delivered by email or on the page?

This framework unlocks the file on the page immediately. A later backend integration can also send the same resource by email if you want a hybrid flow.
