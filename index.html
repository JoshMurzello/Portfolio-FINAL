How I Work

Build fast, validate hard, ship the clean version.

The pattern is consistent whether I’m working on hardware, a manufacturing fixture, or a digital tool: define the constraint, prototype under real conditions, instrument what matters, and keep refining until the thing earns trust.

Frame

Start from the real constraint

Production limits, user friction, manufacturability, or interaction quality drive the first decision.

Prototype

Make the rough version early

I test with hardware, CAD, code, and visuals before polishing so the core idea proves itself.

Refine

Keep only what survives contact

The portfolio follows the same rule: show the artifact, state the constraint, and make the result easy to judge.
